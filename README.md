# Desmod Assistant

Нативный голосовой помощник для Windows. Постоянно слушает выбранный микрофон, показывает живую расшифровку, понимает команды, запускает приложения и сайты, делает скриншоты, управляет записью NVIDIA и отвечает голосом.

![Интерфейс Desmod Assistant](docs/interface.png)

## Возможности

- постоянное локальное распознавание русской речи через Vosk;
- выбор любого доступного микрофона и индикатор уровня сигнала;
- живая расшифровка прямо в строке ручного ввода;
- настраиваемое кодовое слово, по умолчанию — «Помощник»;
- голосовые ответы и выбор установленного голоса Windows;
- необязательный нейросетевой голос через подключённый API;
- резервная строка ручного ввода;
- запуск YouTube и попытка открыть последнее видео указанного канала;
- запуск Dota 2, Steam, CapCut и TLauncher;
- создание снимка всех экранов;
- переключение записи NVIDIA сочетанием Alt+F9;
- открытие сайтов;
- тёмная и светлая темы с плавным переходом;
- собственный фон: PNG, JPG, GIF, MP4 или WMV;
- автозапуск вместе с Windows;
- подтверждение перед выключением или перезагрузкой;
- необязательное подключение API ИИ для свободного диалога;
- ИИ-планировщик для свободных команд: сайты, поиск и запуск установленных приложений;
- раздел «Нужна помощь» с Google-входом, обращениями и ролями;
- панель владельца, администратора и модератора;
- анимированная стартовая заставка «Desmod Assistant by Desmod.G».

## Быстрый старт

1. Скачайте архив `DesmodAssistant-win-x64` из раздела **Actions** или **Releases**.
2. Распакуйте архив.
3. Запустите `Desmod.Assistant.exe`. Русская офлайн-модель уже включена в релиз.
4. Разрешите Windows доступ к микрофону, если появится запрос.
5. Скажите: «Помощник, открой YouTube».

Для распознавания речи и базовых команд интернет и API-ключ не требуются. Для понимания произвольных действий добавьте OpenAI-совместимый ключ и endpoint во вкладке «Настройки».

## Google-вход и поддержка

1. В Google Cloud Console создайте OAuth Client ID типа **Desktop app**.
2. Скопируйте Client ID в «Настройки → Google и поддержка».
3. Сохраните настройки и откройте «Нужна помощь».
4. Владелец определяется по защищённому хешу аккаунта и получает панель ролей автоматически.

Без адреса сервера поддержки обращения хранятся локально на компьютере. Поле backend URL подготовлено для подключения общего сервера команды.

## Примеры команд

- «Помощник, открой YouTube»
- «Помощник, открой канал Димы Масленникова и запусти последнее видео»
- «Помощник, открой Доту»
- «Помощник, запусти Steam»
- «Помощник, открой CapCut»
- «Помощник, сделай скриншот»
- «Помощник, запусти запись экрана»
- «Помощник, открой сайт github.com»

Скриншоты сохраняются в `Изображения\Desmod Assistant`.

## Сборка из исходников

Требуется Windows 10/11 и .NET 8 SDK.

```powershell
dotnet restore
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -o publish/win-x64
```

## Приватность и безопасность

- Базовое распознавание речи выполняется средствами Windows.
- API ИИ используется только после добавления пользователем ключа.
- Потенциально опасные системные команды требуют явного подтверждения.
- Приложение не обходит защиту Windows и не получает права администратора автоматически.

## Ограничения версии 1.0

- Качество распознавания зависит от микрофона и фонового шума; облегчённая русская модель оптимизирована для локальной работы.
- Произвольные интеллектуальные действия требуют подключённой ИИ-модели; ключ подписки ChatGPT не является API-ключом.
- Автоматический выбор последнего видео зависит от доступности публичной выдачи YouTube.
- Пути некоторых приложений могут отличаться; в таком случае Windows должна находить приложение по имени.
